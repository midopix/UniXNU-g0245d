# FocalTech ft8716 1080p DSI video panel — G0245D
#
# Source: stock QFIL package board.dtb, node
#   qcom,mdss_dsi_ft8716_1080p_video (panel-name "ft8716 1080p video mode dsi panel").
# DCS packets below are decoded from qcom,mdss-dsi-on-command / -off-command
# with the qcom mdss-dsi-panel.txt binding format:
#   [dtype][individual][vc][ack][wait_ms][len_be16][payload...]
# The trailing 0x00 parameter byte on 0x05-type packets is verbatim from the
# stock DTS (the 3.18 mdss driver sends the payload as-is).
#
# Panel mode:
#   resolution   1080 x 1920 (0x438 x 0x780)
#   refresh      60 fps
#   bpp          24 (rgb888), color order rgb_swap_rgb
#   lanes        4, lane_map_0123, burst mode
#   porches      hfp 32, hbp 32, hpw 4; vfp 16, vbp 16, vpw 2
#   h/v total    1148 x 1954 -> pixel clock 1148*1954*60 = 134.558 MHz
#   DSI clock    pixel_clock * 3 / 4 lanes = 100.919 MHz
#   on/off state on: dsi_lp_mode, off: dsi_hs_mode
#   backlight    min 1, max 0x3b9 (953), reset seq [1,10,0,10,1,10] ms,
#                lp11-init, t-clk-post 0x13, t-clk-pre 0x2e
